# Paperback Extensions

A repository for [Paperback](https://github.com/Paperback-iOS/app) (v0.9) manga extensions.

## Available Sources

- ManhuaFast

## Installation

1. Open Paperback
2. Add this repository using this link: `https://nicartjay.github.io/PaperbackExt/0.9/stable/`
3. Install and enjoy reading!
