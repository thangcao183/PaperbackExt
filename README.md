# Paperback Extensions

A repository of community manga/manhua/comic extensions for
[Paperback](https://github.com/Paperback-iOS/app) **v0.9**.

Most sources are converted from the
[keiyoushi Tachiyomi extensions](https://github.com/keiyoushi/extensions-source):
the English [Madara](https://mangabooth.com/) (WordPress) sources are generated
from a single shared template, plus a handful of standalone custom sources.

## Installation

1. Open Paperback (v0.9 or newer).
2. Go to **Settings → Extensions → Add Repository**.
3. Paste this URL:

   ```
   https://nicartjay.github.io/PaperbackExt/0.9/stable/
   ```

4. Install the sources you want and enjoy reading.

> Some sources sit behind Cloudflare. The first time you open them
> Paperback may show a Cloudflare challenge in a webview — solve it once and
> the cookies are stored for subsequent requests.

## Project Layout

```
src/
  <SourceName>/
    main.ts        # source instance (Madara sources are one-liners)
    pbconfig.ts    # extension manifest (name, version, content rating, ...)
    static/
      icon.png     # source icon (from the upstream keiyoushi source)
  utils/
    madara/
      template.ts       # shared Madara base used by all Madara sources
    url-builder/
      base.ts           # URL builder helper
      array-query-variant.ts
```

The Paperback bundler only treats a `src/` subfolder as a source when it
contains **both** `main.ts` and `pbconfig.ts`. Everything under `src/utils/` is
shared code and is ignored by the bundler, so the template can be imported via
a relative path (e.g. `../utils/madara/template`).

### Madara sources

All Madara (WordPress) sources share one implementation in
`src/utils/madara/template.ts`. Each source's `main.ts` is just a small config:

```ts
import { ContentRating } from "@paperback/types";
import { MadaraExtension } from "../utils/madara/template";

export const source = new MadaraExtension({
  name: "ManhuaFast",
  baseUrl: "https://manhuafast.com",
  mangaSubString: "manga",
  useNewChapterEndpoint: false,
  contentRating: ContentRating.MATURE,
  langCode: "🇬🇧",
});
```

`mangaSubString` and `useNewChapterEndpoint` are ported per-source from each
upstream Kotlin source. The template implements popular/latest discovery,
search, manga details, chapters (with the AJAX chapter-list fallback), page
lists, lazy-image attribute fallbacks, status normalization, and the Cloudflare
challenge interceptor.

### Standalone sources

Sources that are not Madara-based (currently **LikeManga**) have a fully
self-contained `main.ts` that implements the Paperback interfaces directly.

## Building

Requirements: Node.js 20+.

```bash
npm install        # install dependencies
npm run tsc        # typecheck (tsc --noEmit)
npm run bundle     # produce ./bundles
npm run serve      # serve ./bundles locally for testing in the app
```

`npm run bundle` outputs one folder per source under `bundles/`, plus
`versioning.json` (the repository manifest) and `index.html`.

## Deployment

Pushing to the `0.9/stable` branch triggers the
`.github/workflows/bundle-deploy.yaml` GitHub Action, which bundles every source
and publishes `bundles/` to the `gh-pages` branch under `0.9/stable/`. GitHub
Pages then serves it at the install URL above.

## Versioning

Versions mirror the upstream keiyoushi version for each source.

- **Theme (Madara) sources:** `versionName = 1.4.(baseVersionCode + overrideVersionCode)`,
  where the Madara theme `baseVersionCode` is `51`.
- **Standalone sources:** `versionName = 1.4.(extVersionCode)`.

To pick up upstream updates, re-pull the keiyoushi repo, recompute each version,
and bump any source whose upstream number increased.

## Notes & Limitations

- These sources are generated from the shared Madara base logic. Standard Madara
  sites work the same way the reference source (ManhuaFast) does.
- A few upstream sources have heavy custom behavior (e.g. image decryption,
  custom endpoints — such as Hiperdex, Manga18fx, HentaiRead, Reset Scans,
  Manga District). The shared template does not replicate every custom override,
  so those may have partial functionality.
- These extensions are **not affiliated** with the source websites. They only
  scrape publicly available pages.
